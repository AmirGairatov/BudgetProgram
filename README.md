# Бюджет

Личное веб-приложение для учёта денег: карты и наличные отдельно, расходы, доходы, переводы между счетами, категории и статистика. Сделано под iPhone, работает в браузере, без регистрации.

**Открыть:** https://amirgairatov.github.io/LerasProgram/

## Как поставить на iPhone

1. Откройте ссылку в **Safari**.
2. «Поделиться» → **«На экран "Домой"»**.
3. Запускайте с иконки — откроется как обычное приложение, без адресной строки, и будет работать даже без интернета.

Это важно: iOS может очищать данные сайтов, которые долго не открывали в Safari, а у приложений с экрана «Домой» такого ограничения нет. Но даже если это случится — данные лежат в облаке (см. ниже) и подтянутся заново.

## Где хранятся данные

- **Облако** — приватный репозиторий GitHub [`AmirGairatov/budget-data`](https://github.com/AmirGairatov/budget-data), файл `budget.json`. Видите его только вы.
- **Каждое сохранение — отдельный коммит.** Вся история изменений хранится вечно; любую прошлую версию можно открыть или восстановить: репозиторий → `budget.json` → History.
- **Копия на телефоне** — приложение работает офлайн, изменения отправятся в облако, когда появится сеть. Если вносить данные с двух устройств одновременно, записи сливаются, ничего не теряется.
- **Резервная копия вручную** — «Ещё» → «Скачать резервную копию» (JSON) или «Экспорт в таблицу» (CSV для Excel / Numbers).

### Подключение облака (один раз на каждом устройстве)

1. В приложении: «Ещё» → «Облако» → «Создать токен на GitHub».
2. На странице GitHub:
   - **Expiration** — «No expiration»;
   - **Repository access** — «Only select repositories» → `budget-data`;
   - **Permissions → Repository permissions → Contents** — «Read and write».
3. «Generate token», скопировать токен (`github_pat_…`) и вставить в приложение → «Подключить».

Чтобы подключить второе устройство без повторного создания токена: «Облако» → «Ссылка для другого устройства» и открыть её там. Ссылка содержит токен — отправляйте её только себе.

Если токен потерялся или его нужно отозвать — удалите его в [настройках GitHub](https://github.com/settings/personal-access-tokens) и создайте новый: данные от этого не пострадают.

## Как устроено

Статический сайт без сборки и внешних библиотек: HTML, CSS и JavaScript-модули. Хостинг — GitHub Pages.

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css` | оболочка и оформление (светлая и тёмная тема) |
| `js/app.js` | экраны, формы, навигация |
| `js/store.js` | модель данных, расчёт балансов, слияние версий |
| `js/sync.js` | синхронизация с GitHub |
| `js/charts.js` | графики |
| `js/util.js` | деньги, даты, периоды |
| `sw.js` | офлайн-режим |

Баланс счёта не хранится, а считается: начальный баланс + все операции. Поэтому правка или удаление старой операции сразу корректно меняет баланс. Суммы хранятся в копейках (целыми числами), без ошибок округления.

Чтобы обновить приложение, достаточно запушить изменения в `main` — GitHub Pages опубликует их за минуту.
